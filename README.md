## 🎯 Objetivo

O objetivo deste projeto consiste no desenvolvimento de uma página web estática e responsiva para o portal **TechNews Today**, aplicando técnicas aprendidas em aula de CSS, cumprindo com os requisitos estéticos e estruturais propostos no desafio.

---

## 📝 Descrição do Projeto

O **TechNews Today** é um site simples de notícias sobre tecnologia. 
Ele conta com:
* Cabeçalho fixo com efeito de vidro embaçado (*glassmorphism*)].
* Título colorido em gradiente.
* Card de notícia em destaque com botão de "Leia mais" interativo.
* Layout adaptável que posiciona os itens lado a lado no computador.

---

## 🛠️ Ferramentas Utilizadas

* **HTML:** Estruturação semântica do conteúdo.
* **CSS:** Estilização moderna e layout responsivo.
* **Git & GitHub:** Controle de versões e alojamento do repositório público.
